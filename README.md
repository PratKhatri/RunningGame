# 🏃‍♂️ Running Game

Welcome to **Running Game**, a fast-paced, action-packed game inspired by the classic Google Chrome "No WiFi Dino" game! Avoid obstacles and jump your way to victory as you test your reflexes and timing! 🎮

---

## 🎮 Game Features

- 🏃‍♂️ **Endless Game**: Run through a desert that never ends, avoiding obstacles that increase in difficulty.
- ⏱️ **Dynamic Jumping**: Hold the `Space` key to control the jump time—longer hold, higher jump!
- 🌟 **Scoring System**: Keep track of your score as you avoid the desert obstacles.

## 🕹️ Controls

| **Key**         | **Action**               |
|------------------|--------------------------|
| `Space`          | Jump (Hold to control jump time) |
| `R`            | Restart Game               |

---
## 📜 How to Play

1. **Start the Game**:
   - Launch the game to start running.

2. **Jump to Avoid Obstacles**:
   - Use the `Space` key to jump over the obstacles. Holding the `Space` gives you a higher jump.
     
3. **Avoid Collisions**:
   - Don’t hit any obstacles!
   - Gain +1 score when you pass an obstacle.

4. **Keep Improving**:
   - Try to beat your high score by running further each time and avoiding obstacles with perfect timing.
   - Press `R` to restart game.
